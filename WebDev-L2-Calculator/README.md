# Calculator

**Oasis Infobyte SIP — Web Development & Designing Track — Level 2, Task 1**

## Objective
A functional calculator web app supporting basic arithmetic operations with a clean, dark-themed interface.

## Tech Stack
- HTML5
- CSS3 (Grid layout)
- JavaScript (Vanilla)

## Features
- Addition, subtraction, multiplication, division
- Percentage calculation
- Clear (C) and backspace (⌫) functions
- Decimal point support
- Division-by-zero handling (displays "Error")
- Live expression preview above the current value
- Responsive, centered UI consistent with the rest of the portfolio site

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
