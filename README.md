# OIBSIP# Brew & Co. — Landing Page

**Oasis Infobyte SIP — Web Development & Designing Track — Level 1, Task 1**

## Objective
A visually polished, fully responsive static landing page for **Brew & Co.**, a fictional neighborhood coffee shop. Built to practice foundational HTML5 and CSS3 layout skills.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid, no JavaScript)
- Google Fonts (Playfair Display for headings, Inter for body text)

## Features
- Sticky navigation bar with 4 links (Menu, About, Reviews, Visit Us CTA)
- Hero section with headline, subheadline, and call-to-action button
- Menu/Features section (3 cards)
- About section
- Testimonials section (3 cards)
- Secondary CTA section
- Footer with placeholder contact/social links and copyright
- Consistent warm coffee-tone color palette across all sections
- Fully responsive layout (breakpoints at 768px and 480px) using CSS Grid and Flexbox
- Clear typographic hierarchy (Playfair Display headings vs. Inter body text)

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
