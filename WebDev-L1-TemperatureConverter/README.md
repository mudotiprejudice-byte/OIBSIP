# Temperature Converter

**Oasis Infobyte SIP — Web Development & Designing Track — Level 1, Task 3**

## Objective
An interactive web tool that converts temperature values between Celsius, Fahrenheit, and Kelvin, with real-time input validation and physical edge-case handling.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- Numeric input field with validation (rejects non-numeric input with an error message)
- Unit selector dropdown (Celsius / Fahrenheit / Kelvin)
- Convert button triggers calculation
- Simultaneous display of all three converted units
- Edge case handling: displays a friendly error message for temperatures below absolute zero (−273.15°C)
- Clean, centered, dark-themed UI consistent with the rest of the portfolio site
- Enter key also triggers conversion

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
