# To-Do Web App

**Oasis Infobyte SIP — Web Development & Designing Track — Level 2, Task 3**

## Objective
A task management app to add, edit, complete, and delete to-do items, with data persisted in the browser via localStorage.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Features
- Add new tasks via input form
- Mark tasks complete/incomplete via checkbox (with strikethrough styling)
- Edit task text inline
- Delete individual tasks
- Filter by All / Active / Completed
- "Clear completed" bulk action
- Live task counter
- Data persists across page reloads using localStorage
- Dark, modern-tech themed design consistent with the rest of the portfolio site
- Fully responsive layout

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
