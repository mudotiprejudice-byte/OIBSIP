# Tribute Page — Ada Lovelace

**Oasis Infobyte SIP — Web Development & Designing Track — Level 2, Task 2**

## Objective
A tribute page honoring Ada Lovelace, the world's first computer programmer — featuring her biography, key facts, a timeline of her life, and a memorable quote.

## Tech Stack
- HTML5
- CSS3 (Flexbox)

## Features
- Hero section with styled avatar, name, and life dates
- Biography section
- Key facts list
- Life timeline with year markers
- Highlighted quote section
- Dark, modern-tech themed design consistent with the rest of the portfolio site
- Fully responsive layout

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
