# Personal Portfolio

**Oasis Infobyte SIP — Web Development & Designing Track — Level 1, Task 2**

## Objective
A personal portfolio website showcasing my skills, projects, and contact information — my digital résumé. Styled with a dark, modern-tech aesthetic to reflect a software development identity.

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (smooth scroll navigation)
- Google Fonts (Poppins for headings, Inter for body text)

## Features
- Sticky navigation bar with smooth scroll to each section
- Dark, modern-tech themed design (charcoal background, cyan/violet accents)
- Profile/hero section with glowing avatar, name, and role title
- About Me section
- Skills grid (8 core skills) with hover interactions
- Projects section with 2 project cards (MedBridge AI, Brew & Co. Landing Page) linking to GitHub
- Contact section with name, email, and LinkedIn/GitHub links
- Consistent branding and typography throughout
- Fully responsive layout (breakpoints at 768px and 480px)

## How to Run
Open `index.html` in any modern browser — no build steps or dependencies required.
